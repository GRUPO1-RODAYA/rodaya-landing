# Rodaya – Landing Page

Plataforma móvil y web para el **alquiler de equipos audiovisuales entre estudiantes y propietarios**: una alternativa económica, accesible y segura para que estudiantes de comunicación, cine y carreras afines realicen sus proyectos académicos sin asumir los altos costos de las casas de alquiler tradicionales.

## Segmentos objetivo

- **Estudiantes universitarios / de instituto:** alumnos de cine y comunicación que buscan alquilar equipos por horas y/o días.
- **Propietarios / arrendadores:** alumnos o profesionales que rentan sus cámaras y herramientas inactivas para costear sus estudios o generar ingresos.
- **Trabajadores independientes / filmmakers:** profesionales que buscan tarifas accesibles para producciones audiovisuales.

## Principales características

- Búsqueda y filtros por tipo de equipo, fechas, ubicación cercana al campus y tarifas.
- Alquiler por horas o días, con tarifas estudiantiles.
- Verificación de identidad con carnet universitario / fotocheck y DNI.
- Depósitos de garantía fraccionados.
- Checklist fotográfico obligatorio en la entrega y devolución del equipo.
- Calificaciones y comentarios entre usuarios, y sección comunitaria con recomendaciones de cuidado.
